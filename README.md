沿住東京山手線 corridor 嘅 optimized running route。專為 **駅スタンプラリー (Station Stamp Rally)** 設計！

## 🎯 Optimization Goals

- ✅ **沿山手線鐵路最接近嘅可行走路線** — smoothed railway trace

- ✅ **每個站可以 step off loop 去 stamp counter 再 return**

## 💡 Tips for Stamp Rally

1. **Run along Yamanote railway corridor** — route follows the railway alignment
2. **At each station**: step off the loop → go to stamp counter → return to loop
3. **Longest gap**: 恵比寿→大崎 (3.7km) — pace yourself
4. **Open HTML map** in browser → click any station for prev/next distance info

# 🚃 山手線 Walking / Running Loop

沿住東京山手線嘅行人/跑步環狀路線。GPS 路徑跟 OpenStreetMap 行人可行嘅路！

## 📊 Route Stats

| Metric | Value |
|--------|-------|
| **Distance** | ~51.6 km |
| **Walking** | ~10 hours |
| **Running** | ~5 hours |
| **Stations** | 30 站 (成個圈) |
| **Track Points** | 2,517 |

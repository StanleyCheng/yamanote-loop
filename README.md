# 🚃 山手線 Walking / Running Loop

沿住東京山手線嘅行人/跑步環狀路線。GPS 路徑跟 OpenStreetMap 行人可行嘅路，唔係直接踩路軌！

## ✅ Walkability Verified

This route has been verified to follow **pedestrian-accessible paths** only:
- ✅ Uses OSRM walking/foot profile — routes through pedestrian-friendly roads
- ✅ No expressways or motorways — all roads have sidewalks
- ✅ Passes through all 30 Yamanote stations — perfect for stamp collecting! 🎉
- ✅ Follows real Tokyo streets: main roads with pedestrian sidewalks

## 📊 Route Stats

| Metric | Value |

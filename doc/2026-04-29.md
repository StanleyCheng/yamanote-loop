# 2026-04-29

## Change

- Standardized Traditional Chinese stamp-location wording to use readable `閘口外` phrasing across HTML, JSON, and GPX exports.
- Updated `index.html` to show the 30 stamp locations in the requested order from 東京駅 to 神田駅.
- Updated displayed station names and GPX waypoint names to Japanese station-label form with the `駅` suffix.
- Replaced station stamp text with Traditional Chinese descriptions matching the provided source list.
- Added hover tooltips that show the station name and Traditional Chinese stamp location.
- Replaced the displayed route with an ordered pedestrian route for 東京 -> 有楽町 -> 新橋 -> ... -> 神田 -> 東京.
- Added `stamp_locations.gpx` with all 30 stamp waypoints and the matching walkable loop track.
- Updated `route.gpx` and `yamanote_optimized_running.gpx` to keep GPX exports in sync with the HTML route.
- Corrected `stamp_point.json` so 田町 is not mislabeled as 町田.

## Decision

- Used the supplied checkpoint order as the required visit order.
- Fetched a fresh foot route from `routing.openstreetmap.de/routed-foot` for the ordered station coordinates.
- Used the router's leg distances to recalculate per-station previous/next and cumulative distances.
- Kept station marker coordinates aligned with the existing repository data, while using the supplied stamp descriptions for checkpoint text.
- Used Japanese station-label names with `駅` for display and waypoint names so marker labels match the map-facing station names.

## Why

- `閘口` is clearer and more consistent for station access-point descriptions than the previous `剪票口` wording.
- The previous 48.8 km route did not visit the Shinagawa, Osaki, Gotanda, Meguro, and Ebisu section in the requested sequence.
- The new ordered pedestrian route is about 42.2 km, shorter than the prior route and consistent across HTML and GPX exports.
- Keeping the existing station coordinates avoids an unrelated geocoding change while still routing between all requested stamp checkpoints.
